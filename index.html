📋 How to Use TranslateStack

  1. Copy your Excel column: Select the cells in Excel, press Ctrl+C (Cmd+C on Mac)
  2. Paste below: Each row will appear on a new line
  3. Select languages: Choose source and target language
  4. Translate in bulk: Click translate and get all rows translated at once
  5. Copy back to Excel: Select all translated text and paste back into your spreadsheet
